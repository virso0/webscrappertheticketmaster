# webscrappertheticketmaster
Web Scrapper utilizando a api do site TicketMaster para descobrir e pegar informações sobre eventos ocorrendo no mundo. 

é necessário criar uma conta na API do The Ticketmaster, é de graça, após criar e conseguir sua API_KEY basta colocar ela no arquivo .env
o comando para finalizar o código e impedir que ele fique verificando infinitamente é "ctrl + c" diretamente sob o terminal
